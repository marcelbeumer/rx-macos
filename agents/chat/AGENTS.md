# AGENTS.md

This is a shared folder between regular chat agents sessions.

# When asked to write the conversation or session to disk

- When text only write a file in format yyyymmdd-title.md
- When files generated make a folder in format yyyymmdd-title, inside a file yyyymmdd-title.md and the generated files as-is or whatever makes most sense.

When asked to write the conversation or session to disk another time, update the existing files/folder.

# Resuming conversations/sessions

When asked to resume a conversation/session by filename (full or partially) read the
corresponding files and confirm a short one line summary what
conversation/session we are continuing.
